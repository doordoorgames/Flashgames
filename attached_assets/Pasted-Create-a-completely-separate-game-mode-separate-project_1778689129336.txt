CORE GAME LOOP
━━━━━━━━━━━━━━━━━━

One player currently holds the bomb.

That player:
- solves urgent reactor tasks
- panics under pressure
- experiences visual interference
- can throw/pass the bomb to another player after completing a task

All OTHER players become:
THE CONTROL ROOM

Control room players are NEVER idle.

While waiting:
- they can sabotage
- spam interference
- help or hurt reactor stability
- trigger chaos effects
- distract the active player

The game should ALWAYS feel alive even when it is not your turn.

- tapping
- directional input
- codes

8. FIRE SPREAD
